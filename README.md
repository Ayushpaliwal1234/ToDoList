# ToDoList

# To-Do List Web Application
A simple and responsive To-Do List web application built with HTML, CSS, and JavaScript. This app allows users to add, update, delete, and mark tasks as completed. Tasks are stored persistently in the browser using the localStorage API, ensuring that the list is saved even after page reloads.

# Features
Add tasks: Easily add new tasks to the list.

Update tasks: Edit the title of tasks.

Delete tasks: Remove tasks from the list.

Mark tasks as completed: Toggle the completion status of tasks.

Persistent storage: Tasks are stored in the browser using localStorage, allowing them to persist across page reloads.

Responsive design: Mobile-friendly UI for seamless use across devices.

# Technologies Used
HTML: Structure of the web page.

CSS: Styling and layout, with a focus on responsive design.

JavaScript: Functionality for managing tasks and interacting with localStorage.

# Installation
Clone the repository:
git clone <repository-url>

Navigate to the project directory:
cd todo-list

Open index.html in a browser to view the app.

# How It Works
Add Task: Enter a task in the input field and click "Add" to add it to the list.

Edit Task: Click the task to edit its content.

Delete Task: Click the trash icon next to a task to delete it.

Mark Task as Completed: Click on the task to toggle its completion status.
